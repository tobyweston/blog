## Why this image

A list post: Finder tricks, keyboard shortcuts, workflow shortcuts. No argument,
no mechanism — a collection of small moves.

So the image is a set of keycaps lifted out of a keyboard and arranged as a group,
with one pressed. Shortcuts made physical, and it reads at card size where a
screenshot of Finder never would.

## The mark: a command glyph, not the Apple logo

This post was asked for with the Apple/Mac logo, and that was reconsidered.
Apple's guidelines are the most restrictive of any mark on this site: they permit
referring to products by name in text but do not permit third parties to use the
Apple logo in their own materials, and unlike FreeAgent or Apache they publish no
asset for editorial use. The rights holder's own position is no, not yes-with-
conditions.

So the mark is the command glyph instead. U+2318 is a standard interface symbol —
it long predates Apple's adoption of it, originating as a Nordic sign for a place
of interest — so it carries none of the trademark question while saying "Mac"
instantly to anyone who would read this post.

It is rendered rather than drawn by the generator, which mangles unusual glyphs,
and it is set in the blueprint's own navy so it reads as part of the house style
rather than a logo pasted on:

```bash
H=astro/public/images/heroes/2013-05-24-mac-tips-hero.jpg
magick $H \( documents/brand/command-key.png -resize x150 \) \
  -gravity east -geometry +150-20 -composite -quality 86 $H
```
